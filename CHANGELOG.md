# Changelog

## 1.0.0

- Standalone Windows PowerShell 5.1 capture kit and Python 3.10+ offline readers.
- Known-Folder Documents resolution, explicit game documents and SE/GOG/VR options.
- Generic Papyrus/SKSE heartbeat tracking and explicit custom heartbeat files.
- Both watchers require an unresponsive window and quiet logs; one-shot existing-game mode.
- Per-session collection for MO2/Vortex, generic output locations, cooperative watcher shutdown.
- Disk-space estimate before capture and preserved partial-failure evidence.
- Version-derived optional AE Address Library lookup; explicit SE/VR RVA-only limitation.
- Agent operating guide, privacy/safety rules, human entry point and generic freeze hypotheses.
